If you're looking for information about WebAssembly, the article below is
definitely for you:

➡️
[https://thenewstack.io/will-javascript-become-the-most-popular-webassembly-language/](https://thenewstack.io/will-javascript-become-the-most-popular-webassembly-language/)

### My take:

The article is excellent and covers the topic not so much through technical
"how-to" examples (for that, here's another article
[https://www.yieldcode.blog/post/native-rust-wasm](https://www.yieldcode.blog/post/native-rust-wasm)),
but rather addresses whether WebAssembly is even needed (spoiler: it is), why
JavaScript is the center of its universe, what working tools are already
available today, and the vision for the future of WASM as a whole. In the
article you'll find a large number of links to various projects, initiatives,
and working libraries related to WebAssembly. Enjoy reading

Also, as a supplement, there's a great introductory video on WebAssembly from
Google - [https://youtu.be/RcHER-3gFXI](https://youtu.be/RcHER-3gFXI). It
briefly covers the main topics: what wasm is, where it's used, its portability,
and performance.

#### Creating WASM modules

Below are links to articles about creating wasm modules:

➡️
[https://medium.com/geekculture/webassembly-for-node-js-13ef6bec0a0](https://medium.com/geekculture/webassembly-for-node-js-13ef6bec0a0)
An example of creating a simple module for computing Fibonacci numbers via
recursion. The example is more demonstrative than practical, but very good for
getting a general understanding of the structure and implementation of wasm
modules.

➡️
[https://www.yieldcode.blog/post/supercharge-nodejs-with-rust](https://www.yieldcode.blog/post/supercharge-nodejs-with-rust)
Also creating a Fibonacci computation module, but this time using the
[Neon](https://neon-bindings.com/) framework. The article is more about the Neon
framework than about WebAssembly per se, but that doesn't make it any less
useful.

➡️
[https://www.alxolr.com/articles/how-to-process-a-csv-file-five-times-faster-in-node-js-with-rust-and-napi-rs](https://www.alxolr.com/articles/how-to-process-a-csv-file-five-times-faster-in-node-js-with-rust-and-napi-rs)
A more practical example that you can use as a foundation, since it uses the
[napi.rs](https://napi.rs/) framework for creating wasm modules. The task here
is reading and processing CSV. In this example, as in the previous one, the
execution speed difference for wasm is several times faster, which can be
critically important for this type of task.

P.S. Both examples use [Rust](https://www.rust-lang.org/). In my opinion, it's
the most successful language as a replacement for C/C++ (or at least a worthy
alternative). The language's complexity is well-balanced with its capabilities.
The language is suitable for everything, so knowing it definitely won't be
redundant, especially now that Rust is being adopted by major corporations
everywhere.

So if you're considering learning a new language, I'd highly recommend Rust. For
learning, the [Let's get Rusty](https://youtube.com/@letsgetrusty) YouTube
channel will help. The author does an excellent and lively retelling of the
[official book/documentation](https://doc.rust-lang.org/book/#the-rust-programming-language)
with code examples, and also provides a lot of useful and fresh information
about Rust.
