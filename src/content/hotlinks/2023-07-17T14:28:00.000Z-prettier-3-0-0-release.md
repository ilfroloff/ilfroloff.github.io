Prettier has released major version 3.0.0! There are many changes, all listed
here:

➡️
[https://prettier.io/blog/2023/07/05/3.0.0.html](https://prettier.io/blog/2023/07/05/3.0.0.html)

My take: A very large release. The team made many breaking changes, so you need
to upgrade carefully and treat it as a separate full-fledged task.

The significant changes include:

[#1](https://prettier.io/blog/2023/07/05/3.0.0.html#change-the-default-value-for-trailingcomma-to-all-11479httpsgithubcomprettierprettierpull11479-by-fiskerhttpsgithubcomfisker-13143httpsgithubcomprettierprettierpull13143-by-sosukesuzukihttpsgithubcomsosukesuzuki)
Now `trailingComma: "all"` is the default. To restore the v2 default behavior,
set `trailingComma: "es5"`. Generally speaking, I set `trailingComma: "none"`
because I don't see any advantage in a confusing trailing comma. Some might say
it helps write code faster (supposedly you don't need to constantly think about
whether you've put a comma at the end of an object/array/function/type etc. - it
will be added automatically if autofixers are configured correctly), but I can't
grasp that, because we're not typists, we're programmers. Our main time is spent
on thinking processes, not typing

[#2](https://prettier.io/blog/2023/07/05/3.0.0.html#remove-support-for-flow-comments-13687httpsgithubcomprettierprettierpull13687-13703httpsgithubcomprettierprettierpull13703-by-thorn0httpsgithubcomthorn0)
Removed support for Flow special comments. Too few people use Flow and its
directives, and the code still needs to be maintained - so into the trash rather
than spending time on it. Switch to TypeScript and you'll be happy

[#3](https://prettier.io/blog/2023/07/05/3.0.0.html#typescript) TypeScript
support was nicely improved. Many pleasant changes/fixes for formatting types,
keywords, etc. were added. It used to happen that after running Prettier, types
became less readable than desired. The new version should help with that
